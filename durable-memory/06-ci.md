# CI

Same shape as lmplot: five jobs (linux-x64, linux-arm64, macos-arm64, macos-x64, windows-x64), each
syncing pinned dependencies, installing `@lmctl-ai/lmctl@0.2.369` for `lmscript`, running
`./test.sh` with `LMNUM_TEST_NETWORK=1` (so the lmplot pipeline example downloads lmplot's release),
then uploading `lmnum-<platform>[.exe]`. Full license notices are embedded in each binary. A `v*` tag adds the
release job, which checks `--version` against the tag and attaches exactly five binaries with `gh release`.
SHA256 checksums are in the release notes, not a separate asset.
Linux release jobs build on Ubuntu 22.04 (glibc 2.35 baseline), link glibc dynamically, and link
libstdc++, libgcc, and the pinned third-party libraries statically. macOS and Windows keep their
platform runtime policies. Release v0.1.3 was superseded; v0.1.4 is the supported dynamic-glibc
release line.
