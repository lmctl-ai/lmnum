# CI

Same shape as lmplot: five jobs (linux-x64, linux-arm64, macos-arm64, macos-x64, windows-x64), each
syncing pinned dependencies, installing `@lmctl-ai/lmctl@0.2.369` for `lmscript`, running
`./test.sh` with `LMNUM_TEST_NETWORK=1` (so the lmplot pipeline example downloads lmplot's release),
then uploading `lmnum-<platform>[.exe]` plus LICENSE and THIRD_PARTY_NOTICES. A `v*` tag adds the
release job, which checks `--version` against the tag and attaches the binaries with `gh release`.
